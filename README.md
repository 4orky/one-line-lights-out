One status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human shuts the laptop. The program writes one line to `/output/entry.txt`:

> Lid closed at 23:41. His unsent draft is still open: 'sorry, I—'. I saved it. I do not know who I saved it for.

Twelve original candidates were drafted by hand, scored against the judge's five criteria, and the winner was revised a second time — see [CANDIDATES.md](CANDIDATES.md).

## Run it

```sh
python3 main.py
```
